## 천원돌파 그렌라간 (NDS) 한글패치 — Beta v0.1 (v5 빌드)

첫 베타 배포입니다. **시나리오 대사 + UI + 일부 이미지 텍스트**까지 한글화했습니다.

### 적용법
1. 원본 일본판 롬 준비 (`Tengen Toppa Gurren Lagann (Japan).nds`, 게임코드 `YGRJ`)
2. 아래 `GurrenLagann_KR_beta.xdelta` 다운로드
3. 패치:
   ```
   xdelta3 -d -s "Tengen Toppa Gurren Lagann (Japan).nds" GurrenLagann_KR_beta.xdelta "GurrenLagann_KR.nds"
   ```
   (윈도우는 **Delta Patcher** GUI 권장)

> 롬 파일은 배포하지 않습니다. 패치만 제공합니다.

### 포함된 것
- **시나리오 대사 38,335개** (SPC 스크립트) — 전량 한글

- **맵 이름** 한글 (`지하 마을` 등)
- **한글 폰트** 11×11, 1,028자 신규 생성
- **고유명사 용어집** 적용 (시몬 / 카미나 / 요코 / 니아 / 그렌라간 …)

### 이번에 밝혀낸 핵심 버그
초기 빌드가 스토리 시작 직후 **검은 화면으로 멈추던** 원인은 "맵 이름이 내부 키"라는 가설이 아니라 **쓰기 오프셋 버그**였습니다.

```
SCRP 구조:  10 <len:u16> <Shift-JIS text> 00
             ↑ off (명령코드)      ↑ 실제 텍스트 = off+3
```
`off`에 그대로 덮어써서 `10 <len>` 3바이트를 파괴 → 바이트코드가 깨졌습니다.
**`off+3`부터 쓰도록 수정**하니 맵 이름까지 전부 번역해도 정상 동작합니다.

(별개로, ARM9 헤더 렌더러는 **전각 2바이트 전용**이라 번역에 반각 ASCII가 섞이면 정지하는 문제는 실제였고, 해당 문자열은 전각만 사용하도록 처리했습니다.)
