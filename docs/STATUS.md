## 2. 미해결 (게임 프리징)

### (A) ARM9 UI 문자열 → 로드 파일 선택 화면에서 흰 화면 정지

- 근거: 이분 탐색(`tools/bisect_arm9.py`)으로 1,044개 중 단일 문자열 특정
  - `{이 문자열만 패치}` → 정지
  - `{나머지 1,043개 패치}` → 정상
- 추정 원인: 게임이 이 문자열을 단순 표시가 아니라 **내부 키/조회**에 사용
- 대응: 현재 ARM9 문자열은 전부 원문 유지

### (B) SPC 시나리오 문자열 → 로드 화면 이후 검은 화면 정지
- 재현: 패치 롬 실행 → 타이틀 → 세이브 선택 화면까지 정상 → 이후 **검은 화면 고정**

- 가설

  2. 특정 SJIS 코드가 엔진의 인라인 명령과 충돌
